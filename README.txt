============================================================
Game Note 遊戲筆記網站－功能說明文件
============================================================

專案名稱：game_note_v2
專案用途：記錄個人的遊戲筆記、遊戲收藏與紀念內容。
前端發布：GitHub Pages
線上服務：Supabase Authentication、Database、Storage


一、目前頁面
============================================================

1. 登入頁面
   - 使用電子信箱與密碼登入。
   - 第一次使用時可以建立新帳號。
   - 若 Supabase 尚未設定或連線失敗，畫面會顯示錯誤原因。
   - Supabase 可設定註冊後是否需要驗證電子信箱。

2. 我的遊戲庫
   - 顯示目前使用者建立的所有遊戲。
   - 顯示遊戲名稱與封面圖片。
   - 可以搜尋遊戲名稱。
   - 可以點擊遊戲卡片進入遊戲內容頁面。
   - 顯示遊戲數量、筆記數量與紀念數量。

3. 遊戲內容頁面
   - 顯示目前選取的遊戲名稱。
   - 可以切換「筆記」與「紀念」分頁。
   - 可以返回遊戲庫首頁。


二、目前操作功能
============================================================

1. 帳號功能
   - 電子信箱註冊。
   - 電子信箱與密碼登入。
   - 保留登入狀態。
   - 登出帳號。
   - 每位使用者只能查看及操作自己的資料。

2. 遊戲管理
   - 新增遊戲。
   - 輸入遊戲名稱。
   - 上傳遊戲 Logo 或封面圖片。
   - 上傳圖片前會顯示預覽。
   - 封面圖片大小限制為 5 MB。
   - 支援 JPEG、PNG、WebP 與 GIF 圖片格式。
   - 搜尋已建立的遊戲。

3. 筆記管理
   - 在指定遊戲中新增筆記。
   - 可選擇文字、圖片或影片類型。
   - 輸入筆記標題與筆記內容。
   - 顯示已建立的筆記。
   - 刪除筆記。

4. 紀念管理
   - 在指定遊戲中新增紀念。
   - 可選擇圖片、影片或連結類型。
   - 輸入紀念文字與介紹文字。
   - 可以附加外部網址。
   - 顯示已建立的紀念。
   - 刪除紀念。


三、線上資料功能
============================================================

1. Supabase Authentication
   - 負責帳號註冊、登入、登出與登入狀態管理。

2. Supabase Database
   - games 資料表儲存遊戲名稱及封面網址。
   - entries 資料表儲存筆記與紀念內容。
   - 使用者在不同裝置登入同一帳號時，可以讀取相同資料。

3. Supabase Storage
   - game-covers 儲存空間用於保存遊戲封面圖片。
   - 圖片會依照使用者帳號分開存放。

4. 資料安全
   - 已啟用 Row Level Security（RLS）。
   - 未登入的訪客無法讀寫遊戲及筆記資料。
   - 登入者只能讀寫屬於自己的遊戲、筆記與紀念。
   - 前端只使用 Publishable key。
   - 禁止把 Secret key 或 service_role key 放入專案。


四、GitHub Pages 發布功能
============================================================

1. 專案使用 GitHub Actions 自動發布。
2. 推送到 main 分支後會自動執行部署。
3. 每次部署會為 app.js、config.js 與 style.css 自動加入新的版本號。
4. 自動版本號可避免瀏覽器持續使用舊版快取。
5. 發布網址：
   https://chen0608123.github.io/game_note_v2/


五、響應式畫面
============================================================

1. 支援一般電腦螢幕。
2. 支援平板及較小視窗。
3. 支援手機版面。
4. 小螢幕會自動調整側邊欄、搜尋列與內容排列。


六、目前尚未完整實作的功能
============================================================

1. 筆記中的「圖片」與「影片」目前只有類型選擇，尚未提供檔案上傳欄位。
2. 紀念中的「圖片」與「影片」目前只有類型選擇，尚未提供檔案上傳欄位。
3. 尚未提供編輯既有遊戲、筆記及紀念的功能。
4. 尚未提供刪除遊戲的功能。
5. 側邊欄的「設定」目前尚未建立設定頁面。
6. 尚未提供忘記密碼及重設密碼功能。
7. 尚未提供更換或刪除遊戲封面的功能。


七、主要專案檔案
============================================================

index.html
  網站入口及外部程式載入設定。

style.css
  登入頁面、遊戲庫、筆記、紀念及響應式畫面樣式。

app.js
  頁面切換、Supabase 登入、資料讀寫及圖片上傳功能。

config.js
  Supabase Project URL 與 Publishable key 設定。

supabase/schema.sql
  Supabase 資料表、索引、Storage 與 RLS 安全規則。

.github/workflows/pages.yml
  GitHub Pages 自動部署及防快取版本設定。

page_example/
  專案各頁面的設計參考圖片。


八、使用注意事項
============================================================

1. config.js 必須填入正確的 Supabase Project URL 與 Publishable key。
2. 必須先在 Supabase SQL Editor 執行 supabase/schema.sql。
3. 不可在 GitHub 上公開 Secret key、service_role key 或帳號密碼。
4. GitHub 更新後，請等待 Actions 顯示部署完成再查看網站。
5. 若翻譯或廣告阻擋擴充功能造成畫面異常，可將網站加入擴充功能排除清單。
